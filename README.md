# TCS FP&A Financial Planning & Analysis Model

## Independent FP&A Portfolio Project

This project is an independently developed FP&A financial model based on publicly available financial information of Tata Consultancy Services (TCS).

The objective is to demonstrate the practical application of FP&A concepts including financial analysis, forecasting, budgeting, variance analysis, working capital analysis, cash flow analysis, KPI analysis, and management reporting.

> **Disclaimer:** This is an independent portfolio project and is not affiliated with, commissioned by, or verified by Tata Consultancy Services. The project does not use confidential internal budgets, management forecasts, client-level data, contract-level information, or any other non-public company information.

---

## Project Overview

The model analyzes TCS's historical financial performance for FY2021–FY2025 and develops an independent FY2026 forecast using publicly available financial information and clearly stated assumptions.

The FP&A workflow follows:

**Historical Financials → Financial Analysis → Forecast Assumptions → FY2026 Forecast → Variance Analysis → Management Insights**

## Data Source & Scope

The analysis and forecast are based on publicly available TCS annual reports and financial information.

No confidential internal budgets, management forecasts, client-level data, contract-level information, or other non-public company data has been used.

Where detailed internal operating drivers are not publicly available, historical financial trends and clearly stated assumptions are used instead.
